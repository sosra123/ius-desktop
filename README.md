# ius — сборка .exe (Windows)

Готовый Electron-проект. Приложение работает из тех же файлов
(`index.html` + `app.js`), что и веб-версия — писать код заново не нужно.

## Вариант A — без установки Node.js (сборка в облаке через GitHub)

Ничего ставить на компьютер не нужно — соберёт бесплатный сервис
GitHub Actions.

1. Зайди на [github.com](https://github.com) и зарегистрируйся
   (если ещё нет аккаунта)
2. Нажми **New repository** → дай любое имя (например `ius-desktop`) →
   **Create repository**
3. На странице пустого репозитория нажми **uploading an existing file**
4. Перетащи туда **все файлы и папки** из этого архива, включая
   скрытую папку `.github` (важно — в ней лежит инструкция для сборки).
   Если сайт не показывает скрытые папки при перетаскивании — см.
   раздел "Если `.github` не загружается" ниже.
5. Нажми **Commit changes**
6. Открой вкладку **Actions** вверху репозитория — там автоматически
   запустится сборка (займёт 3–5 минут, значок жёлтый → зелёный)
7. Когда сборка позеленеет — зайди внутрь неё, внизу будет блок
   **Artifacts** → **ius-windows-exe** → скачать. Внутри архива —
   готовый `.exe`

### Если `.github` не загружается
Некоторые браузеры не дают перетащить скрытую папку. Тогда:
- В репозитории нажми **Add file → Create new file**
- В поле имени файла введи ровно: `.github/workflows/build.yml`
  (слэши сами создадут нужные папки)
- Вставь содержимое файла `build.yml` из архива
- **Commit changes**
- Затем обычным перетаскиванием загрузи остальные файлы
  (`package.json`, `main.js`, `preload.js`, `index.html`, `app.js`, `icon.png`)

## Вариант B — локально, если всё же поставишь Node.js

Скачать [nodejs.org](https://nodejs.org) (LTS-версия), затем в папке проекта:

```bash
npm install
npm start      # проверить, что окно открывается
npm run dist   # собрать .exe
```

Готовый файл появится в `release/ius Setup 1.0.0.exe`.

## Про иконку

`icon.png` уже лежит в папке — бирюзовая клякса на чёрном фоне,
она автоматически станет иконкой .exe и ярлыка.
